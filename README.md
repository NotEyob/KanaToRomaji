# A Kana-To-Romaji Translator 

This is a translator so that you can input Kana Characters, and it will give you the Romaji, which row it's in, and a pronounciation guide! Enjoy!

# How to Run and Install

1. **Download** Python Version 3.14.6 Or Later
2. **Download** Both files here and make sure they are in the same folder
3. Go over to your terminal
4. **Cd** into your folder
5. **Run With:**
   "python KanaRomaji.py" for Windows
   "python3 KanaRomaji.py" for Mac/Linux
6. Enjoy
